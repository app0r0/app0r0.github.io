プライバシーポリシー

最終更新日: 2026年10月6日

1. 概要

rclone-imac（以下「本アプリ」）は、開発者本人が自分の Google アカウントのデータを rclone で同期・バックアップするために使う個人用アプリです。

2. 取得する情報

本アプリは、ユーザーが許可した範囲で Google ドライブのファイルとメタデータにアクセスします。アクセス用の OAuth トークンは、ユーザー自身のコンピューター上の rclone 設定ファイルにのみ保存されます。

3. 利用目的

取得したデータは、ユーザーの指示によるファイルの同期・コピー・バックアップのためだけに使います。

4. 第三者への提供

本アプリは、データを開発者のサーバーやその他の第三者に送信・保存・共有・販売しません。データのやり取りは、ユーザーのコンピューターと Google の API の間でのみ行われます。

5. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から取得した情報の利用は、限定的使用の要件を含む Google API Services User Data Policy に準拠します。

6. アクセス権の取り消し

ユーザーは Google アカウントの権限設定 から、いつでも本アプリのアクセス権を取り消せます。

Privacy Policy (English)

Last updated: October 6, 2026

rclone-imac ("the App") is a personal application used by its developer to sync and back up their own Google Drive data with rclone.

The App accesses Google Drive files and metadata only within the scope the user grants. OAuth tokens are stored only in the rclone configuration file on the user's own computer.

Data is used solely to sync, copy, and back up files as instructed by the user. The App does not transmit, store, share, or sell any data to the developer's servers or any third party. Data flows only between the user's computer and Google APIs.

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

You can revoke access at any time from your Google Account permissions.
